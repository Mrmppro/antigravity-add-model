# فعال‌ساز مدل‌های دلخواه در گوگل آنتی‌گرویتی (نسخه ۲.۳۱.۰)

[English](README.md) | [فارسی](README.fa.md)

> **سلب مسئولیت (پچ غیررسمی):** این پروژه یک ابزار مستقل و متن‌باز است و هیچ‌گونه وابستگی رسمی به گوگل ندارد. نام‌های «Google» و «Antigravity» صرفاً جهت توصیف نرم‌افزارهای سازگار استفاده شده‌اند و کلیه حقوق مالکیت آنها متعلق به دارندگان نشان‌های تجاری مربوطه است.

این مخزن شامل پچ سازگاری کامل برای نسخه جدید **Google Antigravity (v2.31.0)** و **Antigravity IDE (v1.107.0)** است که امکان استفاده همزمان از مدل‌های هوش مصنوعی خارجی (مانند OpenAI GPT-4o / o1 / o3، Anthropic Claude 3.5 / 3.7 Sonnet، DeepSeek R1 / V3، OpenRouter، Groq، Mistral، Cerebras، Kimi، Fireworks AI، Ollama، LM Studio، llama.cpp، NVIDIA NIM، Google AI Studio و هر API سازگار با فرمت OpenAI) را در کنار مدل‌های داخلی جمینای فراهم می‌آورد.

این ابزار با تعبیه یک پراکسی HTTP محلی ایمن درون اپلیکیشن الکترون، مهندسی معکوس API داخلی کلودکد (`v1internal`)، ترجمه فرمت درخواست‌ها/پاسخ‌ها و Tool Calling، پشتیبانی از محیط WSL 2 در ویندوز، و ارائه یک پنجره مودال مستقل مدیریت مدل‌ها با کلید میانبر **`Ctrl+Alt+M`** بدون هیچ‌گونه دستکاری مخرب در رابط کاربری اصلی کار می‌کند.

## راهنمای استفاده سریع (نسخه ۲.۳۱.۰)

### ۱. اجرای پچ روی سیستم

در **ویندوز**، کافی است فایل دسته‌ای (`.bat`) متناسب با نرم‌افزار خود را اجرا کنید (یا از اسکریپت‌های PowerShell استفاده کنید):

- **هم نسخه مستقل Antigravity و هم Antigravity IDE**: فایل `repatch-all.bat` (یا `.\deploy.ps1`)
- **فقط نسخه مستقل Antigravity**: فایل `repatch-antigravity.bat` (یا `.\deploy-antigravity.ps1`)
- **فقط نسخه Antigravity IDE**: فایل `repatch-ide.bat` (یا `.\deploy-ide.ps1`)

در **مک (macOS)** یا **لینوکس (Linux)**:
```bash
npm run build
bash deploy.sh          # در مک
# یا
bash deploy_linux.sh    # در لینوکس
```

### ۲. افزودن و مدیریت مدل‌های هوش مصنوعی

در نسخه ۲.۳۱.۰، رابط کاربری اصلی برنامه کاملاً دست‌نخورده و بدون دستکاری DOM (Zero DOM Pollution) باقی می‌ماند. پنجره مودال **مدیریت مدل‌ها** را می‌توانید در هر زمان باز کنید:

- **کلید میانبر**: فشردن **`Ctrl+Alt+M`** در ویندوز/لینوکس یا **`Cmd+Option+M`** در مک
- **منوی System Tray**: راست‌کلیک روی آیکون برنامه کنار ساعت ویندوز → **⚙ Manage Custom Models (Ctrl+Alt+M)**
- **منوی اصلی برنامه**: منوی **File → Manage Custom Models...**

#### امکانات پنجره مدیریت مدل‌ها:
1. **افزودن مدل (Add Model)**: انتخاب از بین **۱۵ ارائه‌دهنده از پیش‌آماده** (آدرس API به طور خودکار تکمیل می‌شود).
2. **تنظیمات شناسه مدل**: وارد کردن نام مدل (مانند `gpt-4o`، `claude-3-7-sonnet`، `deepseek-chat`)، نام نمایشی دلخواه و کلید API (که با استاندارد امنیتی **AES-256-GCM** ذخیره می‌شود).
3. **تست اتصال (Test Connection)**: بررسی در لحظه صحت دسترسی و معتبر بودن کلید قبل از ذخیره.
4. **ویرایش و تغییر نام درجا**: بدون نیاز به وارد کردن مجدد کلید رمزنگاری‌شده.
5. **جستجوی سریع**: در صورت وجود بیش از ۳ مدل، کادر جستجو برای فیلتر کردن نام‌ها ظاهر می‌شود.
6. **حذف ایمن**: تأیید حذف درجا بدون پنجره‌های مزاحم مرورگر.
7. **بازیابی کلیدها (Batch Fix OpenRouter)**: در صورتی که آنتی‌گرویتی مجدداً نصب شده باشد و کلیدهای قبلی به دلیل تغییر کلید سیستمی غیرقابل رمزگشایی باشند، بنر هشدار با یک کلیک امکان به‌روزرسانی دسته‌جمعی کلیدها را فراهم می‌کند.
8. **انتخاب در چت**: مدل ذخیره‌شده فوراً در منوی کشویی انتخاب مدل‌های چت آنتی‌گرویتی ظاهر می‌شود.

---

### ۳. اتصال به محیط لینوکس WSL 2 (ویژه ویندوز)

نسخه ۲.۳۱.۰ دارای پشتیبانی یکپارچه از WSL 2 است:
- از منوی **File → Connect to WSL** یا راست‌کلیک روی آیکون Tray گزینه **Connect to WSL** را انتخاب کرده و توزیع لینوکسی خود (مانند Ubuntu) را انتخاب کنید.
- برنامه به صورت خودکار نسخه لینوکسی `language_server` را دانلود، با چک‌سام SHA-256 اعتبارسنجی و در مسیر `~/.antigravity-server/bin/` نصب می‌نماید.
- در هر زمان می‌توانید با کلیک روی **Reopen Locally** به محیط ویندوز بازگردید.

## وضعیت قابلیت Auto Switch در نسخه ۲.۳۱.۰

> [!NOTE]
> جهت حفظ پایداری کامل و جلوگیری از تداخل رابط کاربری در نسخه ۲.۳۱.۰، **مسیریابی خودکار مدل‌ها (Auto Switch) به صورت پیش‌فرض غیرفعال است** تا کنترل کامل انتخاب مدل در دست شما باشد و همان مدلی که در منوی چت انتخاب کرده‌اید مستقیماً پاسخ دهد. کدهای مسیریاب و تست‌های مربوطه در پوشه `src/autoSwitch/` و مستندات `docs/gravity-auto-switch.md` برای استفاده توسعه‌دهندگان حفظ شده‌اند.

## معماری و سازوکار فنی نسخه ۲.۳۱.۰

```
Antigravity Desktop / IDE
  └── Language Server (باینری کامپایل‌شده Go)
        └── --api_server_url → http://127.0.0.1:50999 (پراکسی محلی مجهز به فیلتر)
                                  ├── مدل‌های گوگل → سرور رسمی Google Cloud Code
                                  └── مدل‌های سفارشی → ارائه‌دهندگان خارجی (OpenAI, Anthropic, ...)
```

### تغییرات و سازگاری با نسخه جدید ۲.۳۱.۰
1. **معماری پنجره‌های ترکیبی (`BaseWindow` + `WebContentsView`)**: آنتی‌گرویتی در نسخه ۲.۳۱.۰ ساختار پنجره‌ها را به معماری مدرن لایه‌ای ارتقا داده است (`curtainView` و `hubWcv`). پچ ما به صورت کامل با این ساختار هماهنگ شده است.
2. **پایداری موقعیت و اندازه پنجره‌ها (`windowState.ts`)**: ذخیره‌سازی وضعیت پنجره‌ها با درک چندمانیتوره و پیشگیری از خروج پنجره از محدوده نمایشگر.
3. **پشتیبانی از مرورگر داخلی و سندباکس (`scriptJail` و `webviewBrowser`)**: هماهنگی بدون تداخل با قابلیت‌های جدید مرور وب درون‌برنامه‌ای، مجوزهای دسترسی به میکروفون دسکتاپ (`desktopMic`)، و احراز هویت وب (`WebAuthn / caBLEv2`).
4. **پروتکل آیکون‌ها (`antigravity-favicon://`)**: پشتیبانی از پروتکل اختصاصی فاوآیکون و کش امن فاوآیکون‌ها.

## پرسش‌های متداول و عیب‌یابی (FAQ)

### ۱. آیا مدل‌های اضافه شده در صورت آپدیت نرم‌افزار حذف می‌شوند؟
تنظیمات مدل‌ها و کلیدهای رمزنگاری‌شده شما در پوشه داده‌های کاربری (`userData`) ویندوز در فایل `custom_models.json` ذخیره می‌شوند و با نصب مجدد یا اجرای اسکریپت پچ حذف نخواهند شد.

### ۲. اگر برنامه آپدیت رسمی دریافت کرد چه کاری باید انجام دهم؟
با اجرای مجدد فایل `repatch-all.bat` (یا `repatch-antigravity.bat`) در چند ثانیه پچ روی نسخه جدید اعمال شده و مدل‌ها بدون نیاز به تعریف مجدد فعال می‌شوند.

### ۳. چرا کلید میانبر `Ctrl+Alt+M` باز نمی‌شود؟
مطمئن شوید پنجره برنامه فعال (فوکوس) است. همچنین می‌توانید با راست‌کلیک روی آیکون برنامه در تسک‌بار (کنار ساعت سیستم) گزینه **⚙ Manage Custom Models** را انتخاب کنید.

### ۴. آیا از اجرای فرامین و ابزارها (Tool Calling / Function Calling) پشتیبانی می‌شود؟
بله، پراکسی درخواست‌های ابزارها و فرامین شل (مانند اجرای کد، خواندن و نوشتن فایل) را به ساختار استاندارد مدل هدف ترجمه کرده و پاسخ‌ها را دقیقاً با ساختار مورد انتظار Antigravity بازمی‌گرداند.

## گزارش تغییرات (Changelog)

### نسخه ۲.۳۱.۰ — هماهنگی کامل با معماری Antigravity 2.31.0
- **سازگاری کامل با نسخه رسمی ۲.۳۱.۰**: به‌روزرسانی کدها، ماژول‌ها و مانیفست پروژه جهت هماهنگی با انتشار جدید گوگل آنتی‌گرویتی v2.31.0 و Antigravity IDE v1.107.0.
- **پشتیبانی از پنجره‌های ترکیبی مدرن**: بازنویسی بخش مدیریت پنجره برای سازگاری با معماری `BaseWindow` + `WebContentsView` (`curtainView` و `hubWcv`).
- **مدیریت پیشرفته چندمانیتوره (`windowState.ts`)**: رهگیری دقیق وضعیت، اندازه و جایگاه پنجره‌ها در نمایشگرهای مختلف با ذخیره‌سازی فوری هنگام خروج.
- **هماهنگی با مرورگر داخلی و سندباکس ایزوله**: پشتیبانی بدون نقص از زیرسیستم‌های مرورگر داخلی وب‌ویو، ایزولاسیون اسکریپت‌ها و استاندارد امنیتی احراز هویت WebAuthn.
- **مجوزها و APIهای جدید Preload**: تعریف واسط میکروفون دسکتاپ (`desktopMic`)، پروتکل اختصاصی `antigravity-favicon://` و کنترل‌های وب‌ویو.
- **پایداری محیط اجرا**: بهینه‌سازی `prefetchShellEnv` برای استخراج و نگهداری متغیرهای محیطی بدون افت سرعت.
- **تست‌ها و صحت عملکرد**: پاس شدن ۱۸۹ تست واحد از میان ۹ فایل تستی بدون حتی یک خطا.
